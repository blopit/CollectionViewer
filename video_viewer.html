About This 3D Video

This video was created using a 3D inpainting pipeline that converts regular 2D videos into 3D content. The process involves:

  1. Extracting frames from the original video
  2. Generating depth maps for each frame using MiDaS, a deep learning model for monocular depth estimation
  3. Converting depth maps to 3D meshes using Open3D
  4. Rendering the 3D meshes from different viewpoints to create a novel view video

The resulting video shows the scene from different angles, creating a 3D effect that gives depth to the original 2D content.
